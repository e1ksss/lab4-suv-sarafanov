# Описание проекта

Учебный репозиторий лабораторной работы № 4 по дисциплине «Системы управления версиями» (МТИ).

## Назначение

Отработка работы с удалённым репозиторием GitHub: clone, push, pull, fetch,
командная работа через ветки и Pull Request, настройка .gitignore.

## Структура

| Файл | Назначение |
|------|------------|
| main.py | сглаживание показаний датчика температуры скользящим средним |
| README.md | краткое описание и автор |
| description.md | подробное описание проекта |
| .gitignore | исключения: артефакты Python, виртуальные окружения, файлы IDE и ОС |

## Запуск

python main.py
